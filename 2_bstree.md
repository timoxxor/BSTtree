# Домашнее задание 2: Реализация BSTree (Binary Search Tree)

## Задача
Реализовать структуру данных **двоичное дерево поиска** (`BSTree` — Binary Search Tree) на языке C++.

---

## Общие требования

1. **Структура проекта:** программа должна быть разделена на заголовочный файл (`.hpp`), файл реализации (`.cpp`) и файл с точкой входа (`main.cpp`).
2. **Интерактивное меню:**
   - программа должна содержать меню выбора действий;
   - после завершения выбранного действия меню должно обновляться и запрашивать действие заново;
   - работа продолжается до ввода пользователем символа завершения программы (рекомендуется использовать `0`).
3. **ООП и структура:** программа должна представлять собой класс, реализующий двоичное дерево поиска.
4. **Валидация ввода:** программа должна проверять корректность вводимых пользователем данных.
5. **Пространство имён:** все элементы программы должны быть расположены в отдельном пространстве имён (`namespace`).
6. **Инкапсуляция:** реализация должна удовлетворять требованиям инкапсуляции.

---

## Базовая структура узла

Двоичное дерево поиска должно быть построено на основе структуры `Node` со следующим минимальным набором полей:

```cpp
struct Node {
    int data;
    Node* left;
    Node* right;
};
```

---

## Требуемый функционал класса

В классе `BSTree` должны быть реализованы следующие методы и операции:

### Конструкторы, деструктор и операторы
- Конструктор по умолчанию
- Конструктор копирования
- Конструктор перемещения
- Деструктор
- Оператор присваивания
- Перегрузка оператора вывода (`<<`) для вывода дерева в стандартный поток вывода

### Основные операции с деревом
- Добавление узла в дерево
- Удаление узла из дерева
- Удаление всего дерева
- Поиск элемента в дереве
- Слияние $n$ деревьев

### Обходы дерева
- Прямой обход дерева (Pre-order)
- Симметричный обход дерева (In-order)
- Обратный обход дерева (Post-order)

### Работа с файлами
- Сохранение дерева в файл
- Чтение дерева из файла
